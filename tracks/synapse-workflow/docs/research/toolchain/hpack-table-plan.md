# Static HPACK transition oracle

Permitted alternative, 2026-10-17. This is independent of the stopped Prowler experiment; that operation remains stopped. Inputs are the already pinned installed hpack4.2.0 text files huffman_constants.py and huffman_table.py, both fully read. No package imports, decoding of external traffic, sockets, listeners, credentials, key generation or settings changes.

Predefined oracle: parse only the literal codeword/length arrays and literal transition tuples/known flag names using constrained JavaScript text parsers. Build a bit trie from all257 codewords, reject prefix conflicts and invalid code widths, and derive every reachable nibble transition independently by four bit steps. Associate table state IDs with trie-prefix states from root. Expected emission/failure/completion flags and next-prefix identity must agree for all4096 transitions across256 states. Completion means root or at most seven EOS-prefix one bits; EOS itself is rejected. All states must be reachable. A deliberately altered root transition must fail the same comparison, establishing a negative control.

Receipt retains hashes, exact Node version/command, cardinalities, pass/failure, limitations and cleanup. Run once to answer table consistency; no count-driven repeats. Script reads text and writes one new receipt under the owned directory using exclusive creation; it does not execute the upstream decoder. No cleanup of upstream files is necessary. This is internal consistency with the local codeword constants, not independent RFC Appendix B verification, native performance testing, all byte-string enumeration or application exploit validation.
