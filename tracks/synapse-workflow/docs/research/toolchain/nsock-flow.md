## Request construction, fully read files

`nsock/src/nsock_read.c:1–131`: all three public read forms create an event, select a read mode and optional count, enqueue it and return an event ID. They do not themselves establish received bytes, completion or peer identity. The lines-mode contract explicitly permits more than the requested number of lines and describes success with partial data on EOF/timeout. That comment needs enforcement traced in the core handler before treating it as a verified runtime guarantee. The byte count is a minimum request, not a memory ceiling. No local positive-count validation appears in these wrappers.

`nsock/src/nsock_timers.c:1–75`: a timer creates a TIMER event with no I/O descriptor, enqueues it and returns its ID. Deadline computation, clock behavior, cancellation and callback lifetime remain dependencies of event_new and the engine; this wrapper alone proves none of those properties.

`nsock/src/nsock_write.c:1–237`: write/sendto copy payload into the event buffer before enqueueing. Negative lengths invoke strlen, so binary evidence requires an explicit length. sendto also changes the caller's sockaddr port and copies its destination into the event and descriptor peer fields. Address-size and selected family checks here use C assertions; callers/build configuration must be followed before claiming malformed inputs are rejected in every build. There is no assessment authorization check in these wrappers.

The printf adapter first formats into 4096 bytes, then allocates a larger buffer using the reported length and formats again. Formatting failure yields an already-done ERROR/EMSGSIZE event; empty formatted output yields an already-done SUCCESS event without establishing network delivery. Enqueue/dispatch semantics for already-done events remain unread. The ordinary write comment defines timeout in terms of incomplete write, not an application acknowledgement. At DBG_ALL, short payloads can enter logs with nonprintable bytes replaced; sanitization here is presentation rather than secret redaction.

The file headers describe nsock's GPL v2 terms, OpenSSL linking exception and possible separate agreements. These component headers must not be substituted for the complete Nmap distribution licensing analysis.
