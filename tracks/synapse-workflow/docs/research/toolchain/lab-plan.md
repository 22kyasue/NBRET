Oracles: `/normal` origin observes extension-inserted request header; client and saved flow contain extension-appended response marker. `/synthetic` produces extension response and zero origin requests. `/raise` extension inserts request header then raises; origin still sees the request and the client sees origin response (tests logged ordinary exception behavior, not a general failure-policy guarantee). `/kill` explicitly kills flow and does not reach origin. Place fixture mutation addon before Save in chain, preserving ordering in receipt. Save native flows and reread them via upstream FlowReader to compare content and errors. Track exact origin hits, client bytes/status, hook sequence and saved artifacts. Never send fixture request to any other IP/port.

Verify both selected loopback ports refuse new connections after cleanup. Retain fixture source and serialized flow SHA-256 and exact run receipt.
