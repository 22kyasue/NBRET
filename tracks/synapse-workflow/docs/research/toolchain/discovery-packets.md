## Cross-tool example and unresolved evidence

Synthetic reasoning example: an authorized fixture's TCP port is classified open; a service regex identifies an HTTP banner; a packet trace shows handshake and bytes; an application proxy shows a request/response under a synthetic account. These support reachability, identification and observed application behavior respectively. They still do not establish an authorization vulnerability, actual patch level, or visibility of all defender sensors. To validate a tenant boundary, add a seeded-data oracle and expected role/action matrix. To assess detection, correlate controlled activity with sensor collection, alert and response records. Keep scan vantage/source path distinct from collector/victim/defender timestamps.
