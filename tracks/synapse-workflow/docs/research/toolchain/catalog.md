# Dated catalog: editions, releases, source and license boundaries

Checked 2026-10-17. `catalog.json` retains maintainer GitHub repository/release metadata URLs, response status, retrieved time, commit resolution and SHA-256 receipts; raw responses/license artifacts are under ignored `.tools/toolchain/catalog`. These are public metadata observations, not runtime verification. A GitHub `/releases/latest` 404 means no such published release object there, **not** no releases/support. Tags can move: the recorded resolved commit is the reproducibility key. Downloading a license is not complete license interpretation.
