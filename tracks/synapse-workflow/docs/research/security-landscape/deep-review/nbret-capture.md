## src/capture.mjs complete1–249

This is heuristic key redaction, not value-based secret discovery: arbitrary strings under neutral keys, labels, paths and fragments without the keyword remain possible. Hashes bind sanitized content, not the original secret-bearing bytes or principal. 30–39 retains structured JSON/form after key redaction; other bodies retain only byte count. 41–60 validates budgets and explicit origins, opens page CDP session and declares limitations/options. Origins constrain retained bodies/headers, **not browser egress**; no route interception blocks network here.

61–79 tracks actions, requests, sockets and async tasks; entries are counted and pending work limited. Asset budget increments before write, with at most half total allocated to assets. Admission limits retained records rather than all transient memory or browser traffic. 80–107 records navigation, console metadata, request/redirect hops, initiator frames, response/cache/failure metadata. Out-of-scope URL query is stripped but path retained. Principal is not an explicit captured dimension; authorization/cookies are redacted. Temporal action IDs expressly do not prove causality.

108–129 obtains response body after completion, checks encoded and decoded limits, sanitizes then persists by content hash. CDP may return decoded body larger than encoded bound, so second check matters; retrieval transient memory is already allocated before it. Async failure records unavailable status, pending overflow marks omission. 130–149 fetches script source for hashing even when persistence disabled; opted-in source is explicitly unredacted. 150–159 stores WebSocket frame metadata only, caps200/socket, enables CDP domains. 160–166 optionally enables precise coverage and records unavailable status on failure.

167–179 idle wait excludes streaming resource types, waits pending tasks and quiet interval, returns settled=false on deadline; it does not abort remaining traffic. 180–207 snapshots bounded DOM geometry/styles, storage counts, limited link metadata, accessibility heuristics and timing. Links/title/labels are retained text, distinct from structured-body key redaction; safeStateUrl sanitizes href but not arbitrary label text. Snapshot scope check precedes page.evaluate; navigation between those steps needs lifecycle consideration.

208–234 finish sets finished=true first, removes listeners, waits tracked work, collects/stops coverage then detaches CDP. A detach failure happens before finishedAt/serialization/write, while subsequent finish returns in-memory evidence immediately because finished already set. This is a source-predicted finalization recovery gap, pending synthetic validation. No general finally detaches session when enable/snapshot setup fails before recorder return. 235–249 serializes and drops metadata groups in fixed order until total budget satisfied; dropped records may leave already-written asset files. Over-budget base metadata throws. It writes evidence.json directly, without atomic replacement or signature. SHA filenames do not by themselves authenticate evidence provenance.
