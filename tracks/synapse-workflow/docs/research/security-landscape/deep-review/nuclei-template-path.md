## cache.go complete 1–111

This corrects the overly simple path-only-cache suspicion: local modification freshness exists, though mtime is not content digest. 72–96 stores raw or raw-less template and error, records mtime, discards map-set errors. 98–111 Get returns entry without freshness check, Purge clears map. Actual callers must distinguish Has from Get. Cache semantics alone are not a runtime stale-verification exploit.
