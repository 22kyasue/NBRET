## What to review next and why

Avoid adding tools just to fill categories. NBRET already has a ZAP path: review its authorization/context/policy/cleanup implementation before adding a second broad web scanner. Review one Nuclei matcher with one pinned benign template to understand alert semantics. Review one Atomic test with the exact executor and sensor query before calling it detection validation. Add an identity graph collector only after defining whether the question is configuration reachability, usable credentials, actual authorization, or a demonstrated chain.

For application labs, retain a hidden repaired variant and unpublished synthetic cases alongside any well-known training application. For cloud/identity, prepare disposable tenants/accounts and hard egress limits before executing a tool; this collection does not itself satisfy those prerequisites. For hardware, source libraries cannot substitute for devices, bench equipment, firmware provenance and relevant specialist expertise.
