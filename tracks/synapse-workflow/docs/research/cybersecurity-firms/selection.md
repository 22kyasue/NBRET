# Ten representative providers: selection and accounting boundaries

As of **2026-10-17**. This is a mixed sample chosen to explain major product platforms and Japanese delivery businesses. It is **not a verified top-ten ranking**. Security revenue measures sales, market capitalization measures investor valuation, installed base measures deployment reach, and Japanese service relevance measures local delivery fit. They answer different questions.

## Working selection

| Provider unit | Type and reason for inclusion | Financial boundary to establish |
| --- | --- | --- |
| CrowdStrike | Endpoint-led platform with managed response and consulting; explicitly requested | CrowdStrike consolidated subscription versus professional services |
| Palo Alto Networks | Network security plus cloud/security operations platform | Fiscal 2026 products versus subscriptions/support; acquisition scope |
| Fortinet | Network appliances, security subscriptions and operations | Calendar 2025 product versus service, not firewall units alone |
| Microsoft Security | Cloud, endpoint, identity, email, data and SOC ecosystem | Security portfolio is not Microsoft consolidated revenue |
| Cisco Security / Splunk | Network/security platform plus acquired analytics and response | Security category versus observability and company total |
| Google Cloud Security / Mandiant | Cloud controls, security operations, intelligence and specialist services | Google Cloud and Alphabet totals are not security sales |
| Trend Micro | Japan-headquartered global security platform, enterprise and consumer | Trend Micro consolidated versus enterprise/consumer |
| LAC | Japanese managed security, incident response and systems integration | Security services versus systems development |
| NRI SecureTechnologies | Japanese specialist subsidiary with SOC, consulting and owned products | Subsidiary versus parent NRI consolidated |
| GMO Cybersecurity by Ierae | Japanese assessment/response/SOC business, explicitly requested | Specific company versus GMO group or security segment |

Meaningful local presence is a selection requirement still being evidenced company by company. Trend Micro belongs in the Japan-headquartered group despite its global business; headquarters, ownership and customer geography are separate fields.

## GMO entity map

GMO's own history separates certificate/identity security, cyberattack protection and brand protection. GlobalSign's certificate authority business, GMO Brand Security, GMO Flatt Security and GMO Cybersecurity by Ierae are distinct entities; a commercial partnership does not merge their revenue or software. The [group history](https://group.gmo/security-history/) traces GlobalSign joining in October 2006 and the growth of these branches. Its current text also names newer ventures, which require separate entity/ownership verification. Read the [Ierae dossier](gmo-ierae.md) for the selected company's actual services.
