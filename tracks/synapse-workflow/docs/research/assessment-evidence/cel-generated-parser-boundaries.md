## Syntax and diagnostic boundaries

Grammar member53–58 accepts optional select/index markers, while calls use ordinary identifier tokens. Global identifier/function/message productions60–69 differ from escaped field identifiers91–94/207. A grammar-recognized optional or escaped token still needs handwritten feature validation; grammar acceptance does not establish enabled environment capability. Whitespace and line comments are assigned HIDDEN (`CEL.g4:175–176`); the handwritten caller requests channel0. This explains why syntactic traversal differs from source preservation. ## Connection to trustworthy assessment claims

Successful tree construction, absence of a final transient parser error, successful type check and proven business-policy correctness are distinct claims.
