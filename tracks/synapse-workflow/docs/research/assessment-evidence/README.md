## Reading the evidence

**Reported** means an attributed first-party incident statement, which can be incomplete. **Source-established** describes the inspected implementation at its pinned commit. **Lab-validated** applies only to the retained synthetic run. **Inference** and **counterfactual** are reasoning that goes beyond observed facts. **Proposed** identifies an experiment that has not run. There is no customer-environment evidence here.

The useful unit is a claim with an oracle, assumptions, tested cases, evidence, version and expiry conditions. Passing finite tests establishes those outcomes under those conditions. It does not establish universal absence of vulnerabilities. Coverage should describe the tested space and missing access, rather than compress uncertainty into an arbitrary percentage.
