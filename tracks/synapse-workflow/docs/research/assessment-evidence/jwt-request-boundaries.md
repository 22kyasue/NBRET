## Extraction is an explicit policy choice

HeaderExtractor25–33 returns the first nonempty selected header unchanged. BearerExtractor89–96 requires a case-insensitive bearer prefix followed by a space; legacy AuthorizationHeaderExtractor oauth16–21 instead strips that prefix when present but otherwise returns the raw header. OAuth2Extractor23–28 falls back to access_token arguments, whose extractor40–51 parses multipart/form data and intentionally ignores parsing errors before reading req.Form.
