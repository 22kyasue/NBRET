## What a plan depends on

Dispatcher.Add59–69 checks duplicates against the current child map, inserts pointers progressively and returns at a later duplicate without rollback. Parent lookup73–79 falls back only when a child key is absent: child definitions can shadow parent ones despite the isolation-layer description41–43. ## State and error boundaries

Plan75–85 allocates a fresh planBuilder/localVars map per call and returns errors before publishing the root. Comprehension624–660 pushes locals before condition/step, pops iteration locals before result, and removes accumulator after result; early failure leaves that builder map populated but the next Plan starts a new one. This is contrary evidence to a simplistic persistent-local-state claim. Decorators112–123 can still have external side effects before a later planning failure; no rollback contract is present there. No such callback was executed.

The ordinary list planner checks optional indices against bounds532–536, unlike specialized operator branches429–487/492–495 that index known-arity arguments and rely on prior valid AST shape. A manually malformed AST and its actual admission path would need separate evidence; no crash fixture or equivalent stopped operation was attempted.

EvalState21–79 stores supplied ref.Val references by expression ID, deletes nil values and replaces the map on Reset. It is an observation store rather than an immutable evidence artifact; callers must deliberately snapshot/version/retain values. No persistence, redaction, concurrency safety or tenant isolation is provided by that small type itself. Whether a product shares state is a caller question.

## Unknown patterns describe uncertainty, not a grant

AttributePattern is explicitly mutable53–106, returns its qualifier slice, and PartialActivation retains supplied patterns (activation173–205). Pattern match requires exact qualified variable name100–102 and numeric qualifiers reuse CEL equality174–177. matchesUnknownPatterns250–339 selects candidate patterns, excludes locally bound variables258–260, resolves dynamic qualifier attributes once into temporary static qualifiers274–293, then returns on the first overlapping matching candidate. Prefix overlap is intentionally enough246–249; a pattern for a deeper descendant makes access to its ancestor unknown. Candidate indices are traversed as a map295, so overlapping patterns need not provide a canonical explanation path; no nondeterminism experiment or changed authorization outcome is claimed. Float qualifiers become int64 in returned trails321–322, distinct from numeric-equality matching, so explanation representation should not be assumed lossless for every custom/dynamic number.

Actual matcher371–388 calls AsPartialActivation, whose activation213–223 walks parents; the inline old bug comment373 is not proof that parent lookup is currently missing. Existing activation parent test112–132 and pattern local-bound test340–385 are contrary source evidence. Pattern tests185–235 distinguish match unknown from miss error, but mainly assert unknown type; cross-reference238–320 and final511–534 assert IDs/trails through Contains. Direct qualifier table388–500 includes positive/negative typed equality controls. Globally namespaced test502–508 only checks nonnil construction, not resolution. No exhaustive-pattern proof, runtime result or security bypass follows from these finite authored cases.

A claim evaluator should retain unknown/error/absent/false separately, state the exact unknown-pattern version and prevent unknown from silently becoming evidence of a passed tenant-isolation claim.
